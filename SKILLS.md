# Agent Skills — PulseHype

## Feed adapter engineering
Inspect RSS/JSON parsing, provider timeouts, rate limits and source provenance.

## Ranking evaluation
Expose score components and compare against simple baselines on labelled examples.

## Data quality
Test duplicates, missing timestamps, malformed feeds and time-zone handling.

## Frontend and reliability
Test loading, empty state, partial errors, responsive layout and cache freshness.

Agents must not bypass source restrictions or invent validation evidence.
